# comRS485Qt

Приложение для работы с устройствами по **RS-485 / Modbus RTU** (через COM-порт)
и **Modbus TCP** (через Ethernet). Терминал для обмена сырыми данными и удобный
конструктор запросов Modbus в одном окне.

## Возможности

- **Два способа подключения** — переключаются радиокнопкой:
  - **Serial (Modbus RTU)** — выбор порта, скорости, битов данных, чётности,
    стоп-битов, управления потоком.
  - **Ethernet (Modbus TCP)** — адрес устройства и порт (по умолчанию 502).
- **Сырые данные** — отправка и приём произвольных байт в HEX или тексте.
- **Modbus** — запросы полями формы: адрес устройства, код функции (чтение/запись
  одного или нескольких регистров/катушек), адрес, количество, значение.
- **Журнал** — все входящие и исходящие данные с метками времени, автопрокрутка,
  очистка.
- **Автонастройка сети** (для Modbus TCP) — приложение само назначит сетевой карте
  ПК статический IP в подсети устройства (запросит права администратора), а при
  закрытии предложит вернуть настройки обратно.

## Требования

- Windows 10/11.
- Для работы нужен установленный **Qt** (модули SerialPort и Network) либо
  развёрнутая папка `Release/` с подтянутыми `windeployqt` библиотеками.
- Для автонастройки сети — права администратора и активный проводной адаптер.

## Запуск

Откройте собранный `comRS485Qt.exe` из папки `Release/`. Если собираете сами —
откройте `CMakeLists.txt` в Qt Creator и соберите нужным комплектом (Qt 6, MinGW/MSVC).

## Как пользоваться

1. Выберите тип подключения (Serial или Ethernet).
2. Укажите параметры порта или адрес/порт устройства и нажмите **Подключение**.
3. На вкладке **Сырые данные** отправляйте байты напрямую, на вкладке **Modbus** —
   формируйте запросы полями формы.
4. Следите за обменом в журнале.
